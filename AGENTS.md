# dirtyflags

Python decorator library that tracks when and which instance attributes have changed. See `README.md` for usage and `CONTRIBUTING.md` for contribution conventions.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `jamesxcode/dirtyflags`, operated via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at the repo root plus ADRs in `docs/adr/`. See `docs/agents/domain.md`.
